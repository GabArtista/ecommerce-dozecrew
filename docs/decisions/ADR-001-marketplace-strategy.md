# ADR-001 — Estratégia de Integração com Marketplaces

**Status**: RASCUNHO — será atualizado pelo Agente C após pesquisa
**Data**: 2026-03-30

---

## Contexto

O sistema precisa integrar com múltiplas plataformas de marketplace. A principal preocupação é a simplicidade para o usuário final (lojista sem conhecimento técnico).

## Decisão Pendente

O Agente C (Marketplace Research) irá pesquisar e preencher este documento com:
- Tipo de conexão de cada plataforma (OAuth2 ou credencial manual)
- APIs disponíveis
- Estratégia de implementação recomendada

## Princípio Norteador

> O lojista nunca deve ver a palavra "OAuth", "API Key" ou "Token" na interface. Toda linguagem técnica é abstraída.

## Plataformas em Escopo

1. Mercado Livre
2. Shopee
3. Amazon
4. TikTok Shop
5. Facebook / Instagram Shop
6. Shein (a confirmar viabilidade)
